# 🏥 Kaggle Health Competition

> Решение соревнования Kaggle по многоклассовой классификации состояния здоровья.

## 📌 Описание проекта

Цель проекта — построить модель машинного обучения для предсказания состояния здоровья пациента по медицинским показателям.

В рамках проекта реализован полный ML pipeline:

- анализ структуры данных;
- исследовательский анализ данных (EDA);
- обработка пропусков;
- feature engineering;
- кодирование категориальных признаков;
- обучение модели LightGBM;
- оценка качества;
- генерация submission для Kaggle.

Проект разрабатывался как максимально приближенный к реальному workflow Data Scientist.

# 🔍 Исследовательский анализ данных

В ходе EDA были выполнены:

- анализ структуры датасета;
- поиск пропусков;
- исследование распределений признаков;
- анализ категориальных переменных;
- построение визуализаций;
- исследование корреляций;
- анализ дисбаланса классов.

Для обработки данных преимущественно использовалась библиотека **Polars**, позволяющая работать с табличными данными быстрее классического Pandas.

---

# 🛠 Feature Engineering

В проекте были реализованы:

- создание индикаторов пропусков;
- заполнение числовых признаков медианой;
- заполнение категориальных признаков отдельной категорией;
- построение производных признаков;
- подготовка категориальных переменных для LightGBM.

Feature engineering отделён от этапа обучения модели, что делает pipeline легко расширяемым.

---

# 🤖 Обучение модели

Используется алгоритм:

- **LightGBM (Gradient Boosting Decision Trees)**

Особенности обучения:

- multiclass classification;
- обработка категориальных признаков;
- учёт дисбаланса классов через `sample_weight`;
- использование `Balanced Accuracy` в качестве основной метрики.

---

# 📈 Метрика

Для оценки качества используется

**Balanced Accuracy**

Данная метрика выбрана организаторами соревнования, поскольку классы распределены неравномерно.

Также сравнивается качество с наивным baseline.
